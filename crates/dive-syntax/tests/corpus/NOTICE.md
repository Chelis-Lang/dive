# Vendored test corpus

`tla2sany/` is a verbatim copy of `tlatools/org.lamport.tlatools/test/tla2sany/corpus/`
from [tlaplus/tlaplus](https://github.com/tlaplus/tlaplus) at commit
`94d0c5070852b37b801bb8998c436383ab7ee37b`, the commit of `dive`'s default TLC/SANY oracle.
Only the upstream `README.md` was left out.

Upstream describes this as the "Unified TLA⁺ Syntax Test Corpus". It is shared with
[tree-sitter-tlaplus](https://github.com/tlaplus-community/tree-sitter-tlaplus), and
SANY's own `TlaPlusSyntaxCorpusTests` runs it. It contains 355 tests in tree-sitter
corpus format, in 32 files plus 11 under `unicode/`.

The corpus is MIT-licensed; the licence text is in `tla2sany/LICENSE`.

`sany-verdicts.txt` records, for each test, whether the pinned SANY parser accepts its
input. It was generated by running the pinned SANY jar on each test input; see
`crates/dive-syntax/acceptance/README.md`. Do not edit it by hand.
