# Vendored cfg corpus

Each line of these files holds one TLC model configuration verbatim (`cfg`, or
`cfg_base64` if it is not UTF-8), together with how the pinned TLC reads it (`tlc`).

- `examples.jsonl`: every `*.cfg` in [tlaplus/Examples](https://github.com/tlaplus/Examples)
  at commit `6a7b26a31c1a6aeec789b455e9bbfa3b3ad2728f`. MIT licence, copyright "The TLA+
  project and other contributors" (`LICENSE.md` in that repository).
- `tlaplus.jsonl`: every `*.cfg` in [tlaplus/tlaplus](https://github.com/tlaplus/tlaplus)
  at commit `94d0c5070852b37b801bb8998c436383ab7ee37b`, most of them under
  `tlatools/org.lamport.tlatools/test-model/`. MIT licence (`LICENSE` in that repository).

The files are generated by `crates/dive-config/acceptance/regenerate.sh`. Do not edit them
by hand.
