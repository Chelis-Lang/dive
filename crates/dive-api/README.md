# dive-api

The embeddable Rust API of dive: parse and analyze TLA+ specifications, model-check them, simulate them and validate counterexample traces, with versioned JSON reports.

This crate is part of [dive](https://github.com/Chelis-Lang/dive), a native Rust
TLA+ toolchain whose model checker reports the same results as TLC. Most users
want the `dive-cli` command-line tool or the `dive-api` library.
API documentation is on [docs.rs](https://docs.rs/dive-api).
