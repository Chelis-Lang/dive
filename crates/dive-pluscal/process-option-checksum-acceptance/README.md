`verify.py` reads the immutable delivery hashes. To run a fresh full campaign,
compile OptionValidatorProbe.java against the pinned jar, then invoke
`full-controls.py --java JAVA --jar PINNED_JAR --native DIVE --validator CLASS_DIR
--cst STRICT_CST_ADAPTER`. Use a fresh copy of the evidence directory because
runner output directories intentionally refuse overwriting previous campaigns.
The strict CST adapter is the dive-pluscal/examples/translate.rs Cargo example with --cst;
the editor API example is `dive-pluscal/examples/rewrite.rs`. The runnable
CLI/Rust guide is `docs/pluscal-process-checksum-options.md`.
