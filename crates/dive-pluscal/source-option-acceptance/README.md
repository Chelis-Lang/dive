# Source option admission guard

The pinned translator recognizes source `PlusCal options (...)` declarations.
Native generation and algorithm CRC derivation refuse that unproved context by
name before returning an artifact or checksum. Pass supported settings explicitly
through the CLI/API instead. This guard does not claim source option parsing.

`validator-context/` retains six configured/unconfigured Validator pairs and
four source declarations, including the original wrongly admitted weak/strong
outputs. `source-spacing/` retains 20 clean C/P spacing controls: all primary
recognized weak-fairness declarations are refused. Missing-parenthesis context is
conservatively refused; the reference ignores attached keyword/punctuation forms.
`source-guard/` retains 32 CLI/core checksum surface controls in both profiles.

Those archived surface captures used the broader option producer, whose exact
guard helper and calls are copied here. They are historical evidence, not fresh
guard-only binary certification. The dedicated source_options test freshly checks
this isolated source. Parent integration must rerun the surfaces and full gate.
No runtime Java dependency, model proof or family certification is claimed.
