=== dive --help ===
dive {version}
Deterministic Invariant Verification Engine

USAGE:
    dive <COMMAND> [ARGS]

COMMANDS:
    check           Check a model exhaustively
    worker          Serve safety work for a distributed `dive check`
    tlc             Check a model with TLC's command-line arguments
    dfid            Check a model by bounded iterative deepening
    simulate        Explore random bounded behaviors
    parse           Parse a specification or configuration
    analyze         Resolve modules and analyze a specification
    translate       Translate PlusCal into TLA+
    validate-trace  Validate a counterexample independently
    explain         Explain an error code
    debug           Debug a safety check over the Debug Adapter Protocol (experimental)

    dive parse [FILE.tla] [--config FILE.cfg] [--output human|json] [--cst]
    dive translate <FILE.tla> [--compat=tlc] [--rewrite|--write] [--checksums tla|full] [--replace-modified] [--ast|-writeAST] [--output human|json] [--library-path DIR]... [--module-path DIR]...
    dive analyze <FILE.tla> [--output human|json] [--library-path DIR]... [--module-path DIR]...
    dive debug <FILE.tla> [--stdio|--listen 127.0.0.1:PORT] [--compat=tlc]
    dive explain <CODE> [--output human|json]
    dive tlc [OPTIONS] SPEC[.tla] (TLC checking arguments; see dive tlc -help)
    dive check <FILE.tla> [--config FILE.cfg] [--compat=tlc] [--exit-codes native|tlc] [--store fp|exact] [--seed N] [--fp N]
               [--workers N|auto] [--sequential] [-deadlock] [--action-composition off|tla]
               [--symmetry-liveness unreduced|refuse|tlc]
               [--independent-frontier] [--frontier-memory-bytes N] [--frontier-directory DIR] [--candidate-memory-bytes N] [--candidate-directory DIR] [--store-compact-bytes N] [--output human|json]
               [--time-limit DURATION|none] [--max-memory BYTES|auto|none]
               [--max-states N|none] [--max-depth N|none]
               [--predecessor-memory-bytes N] [--predecessor-directory DIR]
               [--seen-disk-entries N] [--seen-directory DIR] [--seen-key-bytes N]
               [--seen-probe-steps N] [--seen-summary-pairs N]
               [--checkpoint FILE --checkpoint-after-levels N | --recover FILE]
               [--checkpoint-counters tlc|retain]
               [--distributed-worker IP:port]... [--worker-key FILE] [--worker-timeout-ms N] [--distributed-retries N]
               [--core-sample N] [--library-path DIR]... [--module-path DIR]...
    dive worker <FILE.tla> --seed N --fp N --worker-key FILE [--listen IP:port] [--worker-timeout-ms N] [--worker-max-units N]
                [--config FILE.cfg] [--compat=tlc] [--store fp|exact] [--output human|json]
    dive simulate <FILE.tla> --traces N [--generate] [--exit-codes native|tlc] [--depth N] [--seed N] [--aril N] [--stats none|basic] [--time-limit DURATION|none] [--max-memory BYTES|auto|none] [--compat=tlc] [--output human|json]
    dive dfid <FILE.tla> --max-level N [--compat=tlc] [--seed N] [--worker-seeds S,...] [--time-limit DURATION|none] [--max-memory BYTES|auto|none] [--output human|json]
    dive validate-trace <FILE.tla> [--trace TRACE.json] [--inputs RUN.json] [--config FILE.cfg] [--claim ENDING] [--sample]
               [--compat=tlc] [--symmetry-liveness unreduced|refuse|tlc] [--seed N] [--fp N] [-deadlock] [--output human|json] [--library-path DIR]... [--module-path DIR]...

    Eligible ordinary temporal checks use deterministic completed-level checks in the dive
    profile and final checking in the TLC profile.
    dive check uses TLC process statuses by default, independently of semantic profile.
    --exit-codes native retains: 0 no error, 1 rejected input, 10 property violated, 11 deadlock,
    12 assumption, 13 evaluation error. Both conventions keep 2 usage, 3 unsupported/resource
    limit, 4 internal error and 5 stopped by a run budget (no verdict).
    --time-limit defaults to none in both profiles, as in TLC; --max-memory defaults to
    half of physical memory (auto) in both. --compat=tlc (or DIVE_COMPAT=tlc) selects existing TLC-compatible behavior; known gaps are documented.
    The compiled Core is the engine of check, simulate, dfid and tlc; what it does not
    implement is a named refusal, never a fallback. --core-sample N
    also compares the successors of N sampled states with an independent evaluator's, in the JSON
    report (core.sample); it is diagnostic and changes no result.
    Options Core does not implement are not listed; they still parse and refuse by name
    (exit 3).

=== dive check --help ===
USAGE: dive check FILE.tla [OPTIONS]

--strategy symbolic     exact finite safety, symbolic JSON reports (Linux release bundle)
--refine-domains        learn reachable members of wide sets in a symbolic search
--config FILE.cfg       configuration (default FILE.cfg beside the source)
--compat=tlc            select existing TLC-compatible behavior
--workers N|auto        worker count; --sequential forces sequential search
--seed N --fp N         replay seed and fingerprint polynomial
--store fp|exact        fingerprint or exact visited-state keys
--output human|json     report format (JSON schema 4)
--exit-codes native|tlc process statuses (default tlc in either profile)
-deadlock               disable deadlock checking
--time-limit DURATION|none --max-memory BYTES|auto|none
--max-states N|none --max-depth N|none
--action-composition off|tla --symmetry-liveness unreduced|refuse|tlc
--core-sample N         compare N sampled states' successors (diagnostic)
--library-path DIR --module-path DIR (repeatable)

Supported storage options:
--independent-frontier --frontier-memory-bytes N --frontier-directory DIR
--candidate-memory-bytes N --candidate-directory DIR --store-compact-bytes N
--predecessor-memory-bytes N --predecessor-directory DIR
--seen-disk-entries N --seen-directory DIR --seen-key-bytes N
--seen-probe-steps N --seen-summary-pairs N
--checkpoint FILE --checkpoint-after-levels N | --recover FILE
--checkpoint-counters tlc|retain

Supported distributed options (pure safety; see
https://github.com/Chelis-Lang/dive/blob/main/docs/user/distributed-safety.md):
--distributed-worker IP:port  a running `dive worker` endpoint; repeat, 2..64
--worker-key FILE       local file holding the shared 32-byte secret
--worker-timeout-ms N   per-operation and per-unit deadline, 1..60000 (5000)
--distributed-retries N retries of a lost source unit, 0..8 (2)
Requires --seed and --fp; temporal properties, SYMMETRY, VIEW and runtime
effects refuse by name. Worker loss past the retries stops with exit 3.

Core is the only engine. Options it does not implement are not listed here;
they and unsupported combinations refuse by name (exit 3), for example
--symmetry-liveness tlc (the --compat=tlc default) with SYMMETRY and temporal
properties.
There is no default time limit, as in TLC; the default memory
limit is half of physical memory. Native process statuses are 0 success,
1 rejected input, 10 property violation, 11 deadlock, 12 assumption failure,
13 evaluation error; both conventions retain 2 usage, 3 unsupported/resource
limit, 4 internal error and 5 stopped by a run budget (no verdict).

=== dive worker --help ===
USAGE: dive worker FILE.tla --seed N --fp N --worker-key FILE
                        [--listen IP:port] [--worker-timeout-ms N] [--worker-max-units N]
                        [--config FILE.cfg] [--compat=tlc] [--store fp|exact]
                        [--output human|json]

Serve pure Core safety work for `dive check --distributed-worker`; starting a
worker proves no model. Give it the same build, FILE.tla, configuration,
--seed, --fp, --compat, --store and -deadlock as the coordinator.

--worker-key FILE       local file holding the shared 32-byte secret
--listen IP:port        listening endpoint (default 127.0.0.1:0, printed)
--worker-timeout-ms N   per-operation and per-unit deadline, 1..60000 (5000)
--worker-max-units N    exit after N completed units (default: serve until killed)

=== dive tlc --help ===
dive TLC checking adapter (supported subset)

USAGE: dive tlc [OPTIONS] SPEC[.tla]
       tlc [OPTIONS] SPEC[.tla]

    -config FILE[.cfg]   configuration (default SPEC.cfg)
    -workers N|auto     worker count (default 1)
    -seed N             signed 64-bit replay seed (always reported)
    -fp N               fingerprint polynomial, 0..130
    -deadlock           disable deadlock checking
    -modelcheck         explicit checking mode
    -simulate num=N     finite enumerating simulation
    -generate num=N     finite constructive simulation
    -depth N            finite simulation depth
    -lncheck default    ordinary; eligible pure requests with -fp 0 use final
    -XmxSIZE            memory ceiling, as for the JVM heap (default: half of memory)
    -h, -help           this supported-subset help

The adapter selects TLC evaluation and TLC verdict statuses on the Core engine.
Dive extensions:
--output human|json; --symmetry-liveness unreduced|refuse|tlc (tlc, the default here, refuses SYMMETRY with temporal properties); --max-memory SIZE|auto|none; --max-states N|none; --max-depth N|none; --config/--workers/--seed/--fp/--lncheck aliases. Native
dive check defaults are unchanged.

-tool output, unbounded/file simulation, DFID, checkpoint/storage and debugger TLC protocols
are not implemented here and refuse by name. This is not full TLC CLI parity.

=== dive translate --help ===
dive translate [OPTIONS] MODULE.tla
Native translation; --rewrite returns a replacement; --write publishes it.
Supported: -label -labelRoot ROOT -reportLabels -nof -wf -sf -wfNext
-termination -noDoneDisjunct -lineWidth N -version V -debug
Write policy: -noold -nocfg -unixEOL (--write opts in to publication)
Original AST: --ast returns bytes; -writeAST writes AST.tla and exits 255
Explicitly unsupported: -spec -myspec -spec2 -myspec2
See https://github.com/Chelis-Lang/dive/blob/main/docs/pluscal-translation.md
for version/AST limits and JSON reports.
