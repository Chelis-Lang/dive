    dive simulate <FILE.tla> --traces N [--generate] [--exit-codes native|tlc] [--depth N] [--seed N] [--aril N] [--stats none|basic] [--engine reference|core|auto] [--time-limit DURATION|none] [--max-memory BYTES|auto|none] [--compat=tlc] [--output human|json]
    dive dfid <FILE.tla> --max-level N [--compat=tlc] [--seed N] [--worker-seeds S,...] [--engine reference|core|auto] [--time-limit DURATION|none] [--max-memory BYTES|auto|none] [--output human|json]
    dive validate-trace <FILE.tla> [--trace TRACE.json] [--inputs RUN.json] [--config FILE.cfg] [--claim ENDING] [--sample]
               [--compat=tlc] [--symmetry-liveness unreduced|refuse|tlc] [--seed N] [--fp N] [-deadlock] [--output human|json] [--library-path DIR]... [--module-path DIR]...

    Eligible ordinary temporal checks use deterministic completed-level checks in the dive
    profile and final checking in the TLC profile; explicit final/short keeps final checking.
    dive check uses TLC process statuses by default, independently of semantic profile.
    --exit-codes native retains: 0 no error, 1 rejected input, 10 property violated, 11 deadlock,
    12 assumption, 13 evaluation error. Both conventions keep 2 usage, 3 unsupported/resource
    limit, 4 internal error and 5 stopped by a run budget (no verdict).
    --time-limit defaults to 30m in the dive profile and none under --compat=tlc; --max-memory
    defaults to half of physical memory (auto) in both. --compat=tlc (or DIVE_COMPAT=tlc) selects existing TLC-compatible behavior; known gaps are documented.
    --engine core (or DIVE_ENGINE=core) runs the compiled Core on supported requests;
    other features are named refusals. --engine auto runs the core where it can and
    otherwise the whole check on the reference engine, naming the engine that ran and why. The
    reference engine is the default. --core-sample N (with the core) also compares the successors
    of N sampled states with the reference evaluator's, in the JSON report (core.sample); it is
    diagnostic and changes no result.
    --coverage 0 requests final TLC logical costs; --source-coverage reports native source work.

USAGE: dive check FILE.tla [OPTIONS]

--config FILE.cfg       configuration (default FILE.cfg beside the source)
--engine reference|core|auto
--compat=tlc            select existing TLC-compatible behavior
--workers N|auto        worker count; --sequential forces sequential search
--seed N --fp N         replay seed and fingerprint polynomial
--store fp|exact        fingerprint or exact visited-state keys
--output human|json     report format (JSON schema 3)
--exit-codes native|tlc process statuses (default tlc in either profile)
-deadlock               disable deadlock checking
--time-limit DURATION|none --max-memory BYTES|auto|none
--max-states N|none --max-depth N|none
--lncheck final --lasso short
--action-composition off|tlc|tla --symmetry-liveness unreduced|refuse|tlc
--allow-io=env,files,exec
--source-coverage --coverage 0 --core-sample N
--library-path DIR --module-path DIR (repeatable)

Supported storage options:
--frontier-memory-bytes N --frontier-directory DIR
--candidate-memory-bytes N --candidate-directory DIR --store-compact-bytes N
--predecessor-memory-bytes N --predecessor-directory DIR
--seen-disk-entries N --seen-directory DIR --seen-key-bytes N
--seen-probe-steps N --seen-summary-pairs N
--checkpoint FILE --checkpoint-after-levels N | --recover FILE
--checkpoint-counters tlc|retain

Supported distributed options:
--distributed-worker IP:port (repeatable) --worker-key FILE
--worker-timeout-ms N --distributed-retries N

Unsupported combinations refuse by name. Reference is currently the default;
Core runs supported requests directly, while Auto may rerun through Reference.
The default time limit is 30m (none under --compat=tlc); the default memory
limit is half of physical memory. Native process statuses are 0 success,
1 rejected input, 10 property violation, 11 deadlock, 12 assumption failure,
13 evaluation error; both conventions retain 2 usage, 3 unsupported/resource
limit, 4 internal error and 5 stopped by a run budget (no verdict).

=== dive tlc --help ===
dive TLC checking adapter (supported subset)

USAGE: dive tlc [OPTIONS] SPEC[.tla]
       tlc [OPTIONS] SPEC[.tla]

    -config FILE[.cfg]   configuration (default SPEC.cfg)
    -workers N|auto     worker count (default 1)
    -seed N             signed 64-bit replay seed (always reported)
    -fp N               fingerprint polynomial, 0..130
    -deadlock           disable deadlock checking
    -coverage 0        final Init/Next logical coverage (supported scalar slice)
    -modelcheck         explicit checking mode
    -simulate num=N     finite enumerating simulation
    -generate num=N     finite constructive simulation
    -depth N            finite simulation depth
    -lncheck final      bounded final checking with deterministic short lassos
    -lncheck default    ordinary; eligible pure requests with -fp 0 use final
    -XmxSIZE            memory ceiling, as for the JVM heap (default: half of memory)
    -h, -help           this supported-subset help

The adapter selects TLC evaluation and TLC verdict statuses. Final checking
retains its reported limits, refusals and independent counterexample validation;
its deterministic short lasso need not be TLC's chosen lasso. Dive extensions:
--output human|json; --symmetry-liveness unreduced|refuse|tlc (TLC quotient currently refuses); --max-memory SIZE|auto|none; --max-states N|none; --max-depth N|none; --config/--workers/--seed/--fp/--lncheck aliases. Native
dive check defaults and its explicit final/short flags are unchanged.

-tool output, unbounded/file simulation, DFID, checkpoint/storage and debugger TLC protocols
are not implemented here and refuse by name. This is not full TLC CLI parity.

=== dive translate --help ===
dive translate [OPTIONS] MODULE.tla
Native translation; --rewrite returns a replacement; --write publishes it.
Supported: -label -labelRoot ROOT -reportLabels -nof -wf -sf -wfNext
-termination -noDoneDisjunct -lineWidth N -version V -debug
Write policy: -noold -nocfg -unixEOL (--write opts in to publication)
Original AST: --ast returns bytes; -writeAST writes AST.tla and exits 255
Explicitly unsupported: -spec -myspec -spec2 -myspec2
See docs/pluscal-translation.md for version/AST limits and JSON reports.
