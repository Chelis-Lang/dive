# Indexed tuple-stack replay evidence

Issue #227 and ADR 0081 add a private Init/all-Next tuple-range proof for finite
process-owned stack functions. This remains a partial #124/F-029 increment.
The checker and its emitted words are unchanged; the independent validator now
admits the eight selected process-stack words in TLC order.

`captured-epoch/` retains the immutable receiving before census and first native
`bad4a3802c09086a327fe7e895a7738c6db81d5b` runtime, selected source archives with portable commit/tree proofs,
all raw selections/results, paired clean primary output, genuine false-proof
mutations and failed preparation epochs. Its binary hashes identify external
immutable executables; executable bytes are not a source archive or certificate.
The verifier checks exact emitted words/full reports except elapsed time, declared
selection cross-products and semantic failure sites. Source archives are selected
Rust/Cargo inputs, not hermetic dependency/toolchain authority. Final qualification
uses a distinct producer and complete literal-input census before its gate.

The source-inductive proof neither consults these words nor forces values or
providers. Arbitrary-state enabledness/lasso APIs retain their separate admission.
Parameterized action-label notes remain visible; only the actual Next relation is
validated for those steps. Canonical and TLC-order results remain separate. No
mixed-set, random/VIEW, runtime-name family or general PlusCal certification follows.

See [the runnable guide](../../../docs/indexed-stack-trace-replay.md) for the actual
CLI and Cargo example, limits and unchanged named refusals.

coordinator scheduling interruption. Neither counts as a completed gate or selected
