# Native actual admission and independent evaluation

The pin resolves operator actuals through `Tool.getOpContext`/`OpLambdaValue`.
Native module implementations are selected by their actual registered metadata.
This slice whitelists only Sequences.Len, Sequences.Head and FiniteSets.Cardinality
with arity one. An additive analysis accessor returns the enum authority after
owned-context and metered configuration/override inspection. It does not certify
purity, argument values or temporal truth, and does not fabricate a user body.

Planner and independent Word separately prove every actual expression and all
captured lexical/dynamic contexts. Pure constant/state actuals retain the original
runtime call and scope. Runtime finite-binding preflight repeats real domain
checks, then inspects stored state/capture/cache values before native evaluation.
No Value equality/hash, provider method, native evaluation, or guessed module/name
is purity authority. Stored function/set ordering and model namespaces are part
of the admission contract; tuples have their existing storage exemption.

The runtime native-input walk shares finite-binding visits, caps them at 50k,
and refuses depth above128. Pre-enqueue work checks cover states, frame slots,
function key/value pairs, explicit elements and cached states. Lazy cached values
are inspected; opaque functions and deferred providers refuse. Frame revisits
may conservatively consume work rather than ignore a different dynamic context.
Native metadata with supplied lexical parent/dynamic captures refuses.

Configured native origin is not represented in OpVal. This increment therefore
refuses the same enum target when configured, redirected or overridden even if
a caller explicitly supplies it. Unknown/builtin/other-native/higher-order and
recursive targets remain named boundaries. IMPURE/LIVE_TLCGET/runtime-name and
pre-bind source/config alias guards stay authoritative, including unused actuals.

Primary controls preserve all runtime and semantic failures. The `PrintT` actual
is unused and clean TLC succeeds, but the facade refuses its host effect. The
projection helper fails on its empty obligation, which is not a pinned runtime
failure. Cardinality over an explicit set state has correct planner fields and
independent words, while final execution still refuses normalized successor-set
storage. Boolean-state IF-set cases independently exercise successful execution.
No default/profile/schedule or dependency-layering change is made.

The initial smoke campaign used uncommitted development bytes based on clean
known-user commit7683204; it was not a clean768 result. Original source, raw
captures and rejected `=<<` fixture observations are preserved. Test development
also found an unassigned constant in its metadata fixture and an invalid attempted
default-profile final call; those were test setup errors. Current controls retain
configured binding and explicit default-profile refusal instead of weakening
the production guard. The final source epoch is committed before frozen gates
and native captures; manifests identify that epoch and actual build inputs.
