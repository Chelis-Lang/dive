# Concrete null-tableau graph commits

This bounded stage uses the actual deterministic safety pool and retains each
accepted original concrete successor, ordinal and action label. Stored target
representatives are separate: an equal function successor must not be replaced
by the initially stored tuple before phase-L collection. One logical worker's
source commits then retain SetOfStates slot/grow order and capacity multiplier.
The native null-tableau graph consumes those receipts and writes actual nodes,
roots, state/action bins and transitions. A receipt still says
`graph_insertion=false`; only the separate completed commit records insertion.

The complete pinned selection has fifteen bound models: twelve finish the
null-tableau graph projection, one requires a tableau, and two record deciding
reference errors. All twelve completed graph fields match natively at 1, 3, 4
and 8 workers with chaos scheduling. Every non-completed observation is retained
and explicitly refused by this staged native contract; no error-class agreement
is inferred merely from both sides failing. The probes call the real FastTool
enumerators and LiveCheck/DiskGraph, bounded to 128 states and 8192 generations;
they are adapters, not the ModelChecker worker loop or an SCC verdict oracle.
Fifteen separate clean TLC runs preserve all end-to-end outcomes. No goldens are
edited or added by these raw capture scripts.

The forced-key synthetic control isolates unwritten-target duplicate transitions
and subsequent written-target suppression using actual LiveCheck. It earns no
fingerprint or model execution credit. Its first scalar-codec failure and the
intermediate observation that real TLC states recompute fingerprints are retained
alongside the corrected synthetic-state capture. The original compiler import
failure is preserved too. The completed 657-test pre-final-audit gate and all its
sources remain in `historical-before-compile-ownership`; the new endpoint control
checks ownership before planning rather than relying on the later capture guard. Sources, selection, stdout/stderr and all historical
matrices are checked by `scripts/check-phase-l-graph.py`.

Native controls cover 128 deterministic random finite graphs against independent
reachable-state/edge construction; constraints, duplicate/seen edges, root order,
growth, tuple/function representations, original labels/ordinals, resource cuts,
zero/overbound workers and hidden captured effects/malformed IDs. Fresh scoped
admission never evaluates an opaque provider to guess purity. Public captured
functions/sets, operator callbacks and namespace-sensitive named scalars are
conservatively refused. Both public graph and capture endpoints check model IR/name-table ownership
before graph planning, the scoped walk, host setup or worker execution; this is not general constructor
certification. Independent
trace checks validate a real violating periodic word and reject altered initial/
Next edges and a holding word. They certify the supplied word, not the graph or
TLC's witness choice.

Run raw captures with `capture.py`, `capture-collision.py` and `capture-tlc.py`,
passing the verified pinned jar, Java (and javac for projections), plus a recorded
`--reason`. Run the native controls with:

```sh
python3 -I scripts/check-phase-l-graph.py
cargo test -p dive-check --test capture --locked
cargo test -p dive-liveness --test phase_graph --locked
cargo test -p dive-liveness written_controls --locked
```

This contract admits exactly one null-tableau OOS. Multiple OOS, dynamic tableau
products, done-state re-enumeration, strict safety/temporal error precedence,
periodic scheduling and TLC-exact SCC/lasso selection remain open under #140.
The complete safety capture runs before temporal evaluation; reported capture
counters are its actual work, never TLC's phase-L stop prefix. Predicate and
commit work executes inline and is reported separately from actual pool width.
Per-level speculative quotas divide remaining generated/retained-edge bounds by
source count before workers start, reserving implicit stutters. They can refuse
a skewed level that fits the older inline global budget. All bounds are entry or
work limits, not aggregate byte accounting. Product-input projection preserves
PEM labels but neither enables strict liveness nor claims a model proof.
