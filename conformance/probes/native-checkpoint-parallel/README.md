# Deterministic parallel native recovery

The preserved `before/` four-run control requests eight workers for CpSymView
and observes actual inline width one in both profiles. Its frozen executable,
source hash matrix, raw output and archives precede this implementation.
`before-authorities/` retains the prior combined current-source manifests and
their exact source bytes. No oracle golden or historical receipt is changed.

ADR 0038's dated implementation addendum extends the same pure finite safety
admission through the existing deterministic parallel engine. Completed-level
barriers retain concrete discoveries, parent ordinals and already-resolved
configured keys in reference order. Recovery starts at the archive's actual
level and can change worker width or chaos scheduling. A boundary-zero pause
truthfully reports actual one before the pool starts; later pauses and resumed
pool execution report their actual width. Explicit `--sequential` remains an
inline comparison mode.

The current matrix is captured into a fresh directory with:

```sh
python3 -I conformance/probes/native-checkpoint-parallel/capture_recovery.py DIVE FRESH_OUTPUT
```

Its full selection is 144 groups: three configured-key cases, both profiles
and stores, 1/4/8 workers, chaos off/19 and barriers 0/1. Each group checks
uninterrupted versus actual resume with Retain, the unchanged TLC counter reset,
and independent original/altered concrete witnesses. This totals 1,008 raw CLI
runs, including 432 independent witness controls. Current success is recorded
only with a pinned executable/source matrix after the complete run finishes.

Additional Rust controls compare cross-width restoration at level three with
uninterrupted inline results, and all native MAX_COUNTER stop-prefix fields
and concrete paths across multiple actions/frontier states, both profiles and
stores, widths 1/4/8 and chaos. The first MAX test incorrectly asserted that a
resource stop carries no retained prefix path; existing inline execution retains
that path. Exact failed test/source/log/binary evidence remains under
`development/initial-prefix-control/`. The corrected test requires both paths
and exact value/action equality, as well as verdict, counts, queue and depth.
No implementation or oracle evidence was changed to resolve that assertion.

Archives remain trusted-local execution state, not authenticated or independent
reachability certificates. Partial resource-stop paths are not invariant proofs.
VIEW/symmetry keys do not validate illegal concrete edges or certify spec
symmetry. Graph/temporal/runtime/effect/name/checker-read/deferred/spill recovery
remains excluded. Archive bounds do not limit total RAM, candidates, worker
scratch, key buffers or ordinary retained search state. Pool width is not a
speedup claim; F-032 remains partial and requires certification work.

See the runnable commands, counter policy, exact bounds and refusals in
[the user guide](../../../docs/native-checkpoint.md).
