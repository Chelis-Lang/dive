# Conformance snapshot

This page summarises the committed Core small-tier baselines, the floor that
`cargo xtask gate --full` and the nightly conformance job ratchet against. Core
is dive's only checking engine. Per-model verdicts, exits, counts, depth and
property names are in the generated baselines:
[default profile](../conformance/baselines/small-core-dive-w1.json) and
[TLC profile](../conformance/baselines/small-core-tlc-w1.json). The
[scoreboard](scoreboard.md) holds the full-tier and release-gate numbers.

Both baselines were generated by the harness against the pinned TLC
`tlc-2026.10.06.014338`, at one worker, with no model filters. The default
profile comes from run `20261107T180312584-dive-small` and the TLC profile from
run `20261107T172208656-dive-small`.

## Reproduction

The nightly job in `.github/workflows/conformance.yml` and
`cargo xtask gate --full` run:

```sh
dive-conformance run --impl dive:core --impl-profile dive --workers 1 --tier small \
  --no-sany --corpus examples --corpus probes --corpus configured-temporal-operators \
  --corpus validation-smoke --jobs 2 --tlc-budgets --budget-cap 900 \
  --baseline conformance/baselines/small-core-dive-w1.json \
  --report-dir <dir> --no-summary
```

and the same with `--impl-profile tlc` against `small-core-tlc-w1.json`. A model
that agreed in the baseline and no longer does, or a changed observable, fails
the run. Refresh a baseline with `report baseline <report.json> --out <path>` in
the PR that improves it.

Keep `--no-summary` (or `--summary <path>`): without it the harness overwrites
this page with its generated summary, and this compact page is maintained by
hand from the baselines to stay under the 100 KB evidence limit.

`small-dive-w1.json` and `small-tlc-w1.json` in `conformance/baselines/` are
the retired Reference engine's floors. They are historical and no gate reads
them.
