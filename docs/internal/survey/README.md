# Survey

This directory records the oracles, corpora and prior or adjacent work that `dive` measures itself against. The original survey was gathered on 2026-10-08. Later comparisons cite their own sources and measurement scope.

| File | Contents |
|---|---|
| `oracles.md` | TLC/SANY releases, pinning, the TLC message and exit-code protocol |
| `corpora.md` | tlaplus/Examples, CommunityModules, ValidationTestSuite, tlaplus test suites |
| `adjacent.md` | verus-tla, Stateright, Apalache, Quint, tree-sitter-tlaplus |
| `oracle-history.md` | Release model of the 1.8.x line, upstream guidance, and a register of semantics-affecting TLC/SANY changes since 1.7 |
| `competitive.md` | Measured competitive analysis of other TLA+ implementations (M2) |
| [Verification workloads](verification-workloads.md) | Native peer results, pinned benchmark inputs, implementation conformance and TLAPS options |
