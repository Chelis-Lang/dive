# 0037: Multiple finite PlusCal process blocks without name rewrites

- **Status:** accepted
- **Date:** 2026-10-10

## Context

ADRs 0032 and 0035 admit a single process's storage, control flow and fairness.
Several blocks share a global state tuple but have different local variable and
program-counter indexing contexts. Reusing a sequential body without proving
ownership can bind a jump or local reference to another process.

## Decision

Admit multiple C/P process blocks when their process names, local variable names
and labels are globally distinct and the ID domains are proved pairwise
disjoint. The bounded proof handles literal nonnegative integers through `u64`,
unescaped string IDs, finite sets and integer intervals without enumerating
intervals. Overlap, unproved domains/escapes, namespace rewriting, cross-process
local references and out-of-process jumps are explicit refusals/rejections.
Other unproved translation families remain refused. No semantic default changes.

Normalize each process body in its own source extent. Combine its actions in
source order with one shared variable vector. Emit scalar constant-ID locals and
`self`-indexed process-set locals in their owning context; actions preserve every
other block's variables. Follow pinned `PcalTLAGen.GenProcSet`, `GenInit`,
`GenProcess`, `GenNext` and `GenSpec`: source-order domain union and CASE branches,
constant wrappers before existential process-set actions, separate process
fairness formulas and the global program-counter/stutter omission decisions.

Resource limits apply to the aggregate action count and generated bytes. Process
cardinality is charged before per-process normalization, then each normalized part
is charged before retention, including the forced-pc pass. Global declarations
are retained once rather than copied into every stored process. The normalized-node
quota is also charged across all retained blocks in both passes. The API validates the
whole generated module and reports an artifact with `model_proved=false` and
`exhaustive=false`; successful translation is never an exploration verdict.
No new dependency edge, Java runtime delegation, host access or file rewrite is
introduced. Preserve formatter grouping, then compare full operator CST;
significant-token equality alone does not establish TLA junction scope.

## Consequences

Retain the complete two- and three-process primary selections, original secondary
adapter failures, prior raw matrices and every refusal. Separate SANY/CST,
finite-model counts at several widths/stores, independent witness/mutant and
full-document comparator controls establish this bounded slice. Full PlusCal,
artifact formatting and API families remain partial and audit-required.
