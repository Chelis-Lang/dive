# 0136: Fresh certification of successor invariant report identities

- **Status:** accepted
- **Date:** 2026-11-01

## Context

A version-2 named invariant word proves its original cause and check order,
but not the diagnostic replay's deciding class or physical status. Issue #713
demonstrates that coordinated primary-2111 headers could bypass the separate
diagnostic certificate in the API, conformance reader and independent word
check. `ErInvConstrained` actually decides 2179 and `ErInvReplayError` actually
decides 2103. Their correct words remain valid after the report is forged.

Refusing all 2111 reports would lose genuine pinned families. In-model primary
insertion can make diagnostic replay skip the failing invariant and retain
2111. Diagnostic replay can also quietly stop at a false predicate or partial
candidate without replacing that class. Existing pinned core-library controls
include two-, three- and four-state words, and a primary value-method error can
still have a completed diagnostic execution. ADR 0135's two-source limit and
requirement for a diagnostic exception cannot prove those cases.

## Decision

Every supported successor-invariant report, including deciding 2111, requires
the same private `InvariantErrorClass` produced by fresh source/configuration
execution after independent logical-word validation. Remove the primary-2111
shortcuts from producer certification, report mapping and report-word admission.
Ordinary word validation remains a distinct API and does not certify a report.

Extend the independent finite admission ledger to exhaust the actual initial
emissions and replay admitted sources in insertion order until the actual
terminal source. Reconstruct off-word siblings and source levels privately;
the submitted path supplies neither global newness nor a traversal transcript.
Keep the existing 64 admitted keys and 256 emissions, bounded scalar/tuple
VIEW keys, fallible growth and host control. Named invariant proofs additionally
admit fully exhausted multiple Init emissions and bounded materialized record
state fields (64 nodes, depth eight). VIEW keeps its single-Init/scalar-state
scope. This replaces ADR 0135's two-source limit for this bounded proof, without importing a checker,
store, caller cache or visited set. It is not a global search-count certificate.

Retain the actual primary insertions during per-action diagnostic generation
and checks. For a named invariant failure, actual diagnostic completion or a
quiet predicate/partial-state stop retains 2111. An actual diagnostic exception
supplies its own typed deciding identity. A primary value-method failure alone
does not prevent a completed-2111 proof; an unproved diagnostic receiver still
refuses. Register/random/I/O and shared lazy effects still refuse. Deterministic
Print/PrintT execute actual argument, rendering and value semantics on the fresh
runtime with the sink suppressed; the class certificate does not certify the
producer's output stream.

A configured pure integer-equality recurrence `[]<>(v = k)` can retain a named
invariant safety error on the first initial source, before any row completes.
The actual initial value of `v` and the literal are integers; behavior temporal
assumptions, later sources and other property forms refuse. This preserves the
existing `GenError/InvariantError` safety case without admitting the four
unconfirmed temporal Next-error words or later receiver scopes.

Report admission checks canonical name and TLC status against the independently
proved deciding identity, and physical status against the caller-selected exit
convention. The CLI/harness convention is TLC independently of semantic profile.
Explicit native-convention reader/validator entry points admit native status 13
for these evaluation errors. Serialized options cannot select that authority.
Source-free conformance mapping refuses these diagnostic identities.

The same ordered driver and existing version-6 VIEW endpoint also prove the
retained assertion, division, ENABLED and TLC-overflow VIEW families through
actual primary and diagnostic execution. Report schema 3 and native versions
1–6 keep their meanings. No new wire endpoint or classifier rule is introduced.

## Consequences

The coordinated class/name/exit forgery is rejected even when both engines emit
matching headers and the original named word validates. Correct deciding
2179/2103 and genuine 2111 families retain independent proof. Missing authority,
exceeded bounds and unproved demand explicitly refuse; owned interruption and
resource/internal failures do not produce a completed certificate.

The existing mixed invariant and runtime VIEW oracle streams remain
Unclassified. The four module-error VIEW streams use their already classified
pinned outcomes. Focused native-word, engine-shadow and pinned-oracle results
remain separate; none implies a census, phase or release qualification.
