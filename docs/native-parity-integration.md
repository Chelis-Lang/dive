# Native parity integration increment

This increment combines six bounded implementation slices and their shared
admission, capture and recovery boundaries. They remain incomplete TLC families.

- Conditional temporal planning preserves the deciding reference error before
  any graph work, using all 24 pinned controls and retained original captures.
- Concrete graph capture retains original successors, action labels and ordinals
  through the actual pool. Twelve completed null-tableau projections match;
  tableau/error boundaries remain explicit. Graph insertion is not an SCC verdict.
- Native pure safety checkpoints recover saved discoveries and ordered frontiers.
  A paused checkpoint is incomplete. Both profiles reset counters like TLC;
  explicit `retain` preserves uninterrupted totals and is labelled an override.
- PlusCal process translation supports bounded disjoint finite blocks, local
  state, pinned weak/strong fairness, label modifiers and option precedence.
  Validated modules are not model proofs.
- Malformed public IR and foreign bound-model metadata stop before assumptions,
  host effects, workers or checkpoint reads. This also applies to concrete graph
  capture at invalid worker widths.

The original separately verified source trees and their exact compressed bytes
remain in `conformance/probes/native-parity-integration/history`. Their reports
continue to describe those source versions. `current-source.json` identifies the
combined implementation separately. CI verifies both; a new hash cannot replace
an old execution claim. No generated golden or failed selection is rewritten.

The combined gate checks planning-before-capture, the existing concrete graph
and forged-word controls, actual checkpoint pause/resume and admission failures,
full translator artifact controls and ordinary CM1/ValidationTestSuite safety
models. Fresh release captures record their own binary and source identities.

Strict temporal execution, exact SCC/lasso/scheduling, full process translation,
and general checkpoint/runtime/distributed recovery remain pending. Every parity
family still requires its full-selection audit before certification. See
[the parity ledger](tlc-parity.md), [checkpoint details](native-checkpoint.md),
[PlusCal fairness](pluscal-fairness.md) and ADRs 0028, 0029, 0033, 0035, 0036 and 0037.

Source-bound combined release evidence from runtime `9699950` is retained
under `current-controls`: all 576
checkpoint runs, all 404 fairness cases (250 artifacts, 148 rejections and six
refusals), and all 264 multiple-process cases (206 artifacts, ten rejections
and 48 refusals). All 456 artifacts match full operator structure and SANY;
76 finite model controls cover both stores at 1/4/8 workers, including original
and mutated witnesses. Twenty-eight full-document corruptions are rejected.
The original single-process comparator failure is retained: its one-process
assumption was replaced in a separate adapter by checking every process.
CM1 and ValidationTestSuite remain 21 and 16 models at 1/4/8 workers. These
results do not replace the standard whole-selection report.

The later context-alias admission repair (issue #164) is verified separately in

Rust examples. These runs identify their own repaired source and binary. The
older combined captures remain bound to their immutable archived runtime; they
are never retagged as runs of the repaired implementation.
